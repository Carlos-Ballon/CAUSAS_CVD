NoteNota clínica

Los resultados presentados tienen fines de tamizaje escolar y orientación preventiva. Ante valores fuera de referencia, se sugiere evaluación médica especializada.

Se recomienda que, ante cualquier indicador de salud cardiometabólica que supere los valores de referencia establecidos, el escolar sea derivado para una evaluación especializada por pediatría, nutrición, endocrinología o médico general. Como medida inicial, se sugiere implementar pautas nutricionales que promuevan la salud cardiovascular mediante un aporte de grasas totales de entre el 25-30% de las calorías diarias, con un aporte de grasas saturadas entre 8-10% (NHLBI).
